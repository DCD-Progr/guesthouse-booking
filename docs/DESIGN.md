# Interface system

Primary task: guesthouse and date availability, followed by a request and approver room assignment.

White main canvas; pale slate sidebar; dark navy text; teal #007f73 actions; thin slate borders; 8-10px control and table radii; system sans typography. Desktop uses a 216px navigation rail, 72px header and 32px main gutter. Mobile uses a navigation drawer and stacked search controls. Form and data tables use consistent typography and labels.

Component families: shell/navigation, page headings, labelled fields, buttons, status labels, tables, modal forms, metrics and room calendar. No decorative photography is needed. Lucide outline icons mark navigation. Semantic colors accompany text and are not the only state indicator.

The full availability-screen concept guides spacing, heading hierarchy, search, result table and three-step explanation. Intentional implementation differences: live user identity replaces sample names; current dates replace generated example dates; role-appropriate navigation replaces universal navigation; a sample banner is visible only in demo mode; no result is shown until a search runs. Admin/approver screens extend the same table/form visual system.
